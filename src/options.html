ROMarr capture

This extension sends catalogue rows from pages you open yourself to your own ROMarr. It does not browse on its own, does not follow links, and makes no request to any ROM site — it reads the page already in front of you and nothing else.

Your ROMarr

Stored in this browser's extension storage and sent only to the address above, as an X-Api-Key header. Never placed in a URL and never written into a page.

Capture

With this off, nothing leaves the tab until you open the toolbar popup and press Send. Either way the extension only ever sees pages you navigated to yourself.

Sites

Each of these is a site a plain HTTP client cannot catalogue — it needs a session, a form POST, or a page whose links only exist once its own JavaScript has run. Sites ROMarr can already read on its own are deliberately absent; the README says which and why.

Waiting to send

Pages ROMarr could not take — usually because it was down. Retried only when you press the button.
